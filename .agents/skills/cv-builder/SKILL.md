# Curriculum Vitae & Resume Builder Skill

This skill provides an authoritative, end-to-end framework for building, refining, and tailoring Curriculum Vitae (CV) and Resumes. It integrates official standards from **Prospects UK**, the **UK National Careers Service**, and the **Harvard University FAS Mignone Center for Career Success**.

---

## 1. Core Principles & Golden Rules

1. **Document Title**: Never title the document "Curriculum Vitae" or "CV". The candidate's **Full Name** is always the title at the top of the document.
2. **Reverse Chronological Order**: Within Work Experience and Education, always list items in reverse chronological order (most recent first).
3. **Third-Person Narrative (No Personal Pronouns)**: Strictly eliminate personal pronouns (`I`, `me`, `my`, `we`, `our`). Write in concise, active, telegraphic style.
4. **Action-Driven Language**: Every bullet point must begin with an active power verb from Harvard's taxonomy. Avoid passive phrasing, generic claims ("hard worker", "team player"), or starting bullets with dates.
5. **The STAR / CAR Impact Formula**: Every bullet point should express:
   $$\text{[Active Power Verb]} + \text{[Context / Task / Challenge]} + \text{[Skills / Tools / Method Used]} + \text{[Quantified Outcome / Value Added]}$$
6. **No Protected / Discriminatory Data**: Exclude photograph, date of birth, age, marital/family status, and nationality (unless specifically required for visa/legal eligibility).
7. **ATS (Applicant Tracking System) Compatibility**: Clean layout, standard section headings, no multi-column tables, no text boxes, no embedded graphics/icons, and standard fonts (Arial, Calibri, Times New Roman, 10–12pt body, 14–16pt bold headings).

## 2. UK CV vs. US Resume Decision Matrix

Before drafting, determine whether the candidate requires a **UK CV** or a **US Resume**:

| Dimension | UK Curriculum Vitae (Prospects / NCS) | US Resume (Harvard FAS) |
| :--- | :--- | :--- |
| **Primary Audience** | UK, Ireland, Commonwealth, Europe, Academic/Clinical roles | United States, Canada, corporate & private sector |
| **Standard Length** | **Up to 2 full A4 pages** (academic/medical CVs can be longer) | **Strictly 1 page** for students/recent grads; max 2 for 10+ yrs exp. |
| **Introductory Section** | **Personal Statement / Profile** (3–4 sentences, sector-targeted) | **Omitted** or very brief Professional Summary |
| **Paper / Margins** | A4 paper, standard 2.0–2.5 cm margins | US Letter (8.5x11 in), 0.5 to 1.0 inch margins |
| **References Section** | State "References available upon request" or omit to save space | Strictly omit references from the resume document |
| **Detailed Comparison** | See [Standards Comparison](file://./references/standards_comparison.md) | See [Standards Comparison](file://./references/standards_comparison.md) |

## 3. Step-by-Step CV / Resume Construction Workflow

```
┌─────────────────────────────────┐
│ 1. Candidate & Target Profiling │  (Collect history, target job advert, region)
└───────────────┬─────────────────┘
                ▼
┌─────────────────────────────────┐
│ 2. Architecture & Ordering      │  (Education-first vs. Experience-first)
└───────────────┬─────────────────┘
                ▼
┌─────────────────────────────────┐
│ 3. Contact Header & Profile     │  (Clean contact details + punchy statement)
└───────────────┬─────────────────┘
                ▼
┌─────────────────────────────────┐
│ 4. Work Experience & Bullets    │  (Apply Harvard Action Verbs + STAR impact)
└───────────────┬─────────────────┘
                ▼
┌─────────────────────────────────┐
│ 5. Education & Credentials      │  (Degrees, institutions, honors, coursework)
└───────────────┬─────────────────┘
                ▼
┌─────────────────────────────────┐
│ 6. Skills, Tools & Projects     │  (Categorized proficiencies, languages)
└───────────────┬─────────────────┘
                ▼
┌─────────────────────────────────┐
│ 7. Audit & ATS Verification     │  (Proofread, keyword match, formatting check)
└─────────────────────────────────┘
```

### Step 1: Candidate & Target Profiling
1. Collect the candidate's existing experience, achievements, education, credentials, and projects.
2. Review the target **Job Description & Person Specification**:
   - Extract required hard skills, technical stacks, tools, and methodologies.
   - Extract soft competencies and core behavioral keywords.
   - Identify the primary regional style needed (UK vs US).

### Step 2: Architecture & Section Ordering
Choose the layout according to candidate career stage:
- **Students / Recent Graduates**: Contact Info $\to$ Personal Statement $\to$ Education $\to$ Work Experience / Internships $\to$ Leadership & Activities $\to$ Skills $\to$ Interests/References.
- **Experienced Professionals**: Contact Info $\to$ Personal Statement / Summary $\to$ Work Experience $\to$ Education $\to$ Key Skills & Certifications $\to$ Additional Projects.
- **Career Changers / Diverse Backgrounds**: Skills-Based or Hybrid format (highlighting transferable functional skill clusters before chronological history).

### Step 3: Contact Details & Header
- **Full Name** in 18–22pt bold.
- **Location**: City, Region / Country (exclude complete street address when sharing online for fraud protection).
- **Mobile Phone**: Include international dialling code if applying across borders (e.g., `+44 7123 456789`).
- **Professional Email**: Clean format (`first.last@email.com`).
- **Links**: LinkedIn profile URL, GitHub, portfolio, or personal website.
- **Do NOT include**: DOB, gender, marital status, health status, or photo.

### Step 4: Personal Statement / Profile (UK Standard)
A targeted 3 to 4-sentence paragraph answering:
1. **Who you are**: Professional identity and key specialization.
2. **What you bring**: 1–2 quantifiable highlights or marquee skills.
3. **Career aim**: How your ambition aligns with the target sector or organization.
*(Keep it sector-targeted; save job-specific alignment for the Cover Letter).*

### Step 5: Work Experience & Bullet Point Crafting
For each role, structure:
- **Job Title** (Bold) | **Organization Name** | **Location** | **Start Date – End Date (Month Year)**
- Bullet points (3 to 6 per role):
  - Start with a strong action verb in appropriate tense (past tense for past roles, present tense for current).
  - Use the **Harvard / NCS Formula**:
    - *Example (Weak)*: "Responsible for managing social media and team members."
    - *Example (Strong - Harvard Standard)*: "Spearheaded 5-channel digital marketing campaign, delegating tasks across a team of 4 interns and boosting audience engagement by 35% in 6 months."
  - Quantify whenever possible: percentages (%), currencies ($ / £), headcounts, hours saved, volume handled.
  - Consult the [Action Verbs Reference](file://./references/action_verbs.md) for 8 categories of power verbs.

### Step 6: Education & Qualifications
- **Institution Name**, **Location**
- **Degree Title** (e.g., *BSc (Hons) Computer Science* or *Bachelor of Arts in Economics*)
- **Graduation Date / Expected Date** (Month Year)
- **Classification / GPA / Honours** (e.g., *First Class Honours*, *Dean's List*, *GPA 3.8/4.0*).
- **Relevant Coursework / Modules**: List 4–6 relevant modules only if applicable to the job.
- **Dissertation / Capstone Project**: Include title and brief 1-line outcome if relevant.

### Step 7: Skills & Additional Sections
- **Technical Skills**: Programming languages, frameworks, developer tools, CRM, ERP, analytics platforms.
- **Languages**: Categorized by fluency (Native, Bilingual, Professional Working, Conversational).
- **Certifications & Licences**: Issuing authority, credential ID, date attained.
- **Leadership & Activities**: University societies, volunteering, community initiatives (emphasizing leadership).
- **Interests**: Include only if purposeful and demonstrating transferable skills (e.g., endurance running, open-source contributor, event organizer). Leave out generic hobbies (reading, watching movies).

## 4. Special Situations: Gaps, Changes & Disclosures

For detailed instructions, refer to [ATS and Gap Handling](file://./references/ats_and_gap_handling.md):
- **Employment Gaps**: Reframe gaps honestly around upskilling, MOOCs/certifications, freelancing, volunteering, or caregiving responsibilities.
- **Career Transitions**: Emphasize transferable skills (stakeholder management, budget oversight, cross-functional leadership).
- **Disability Disclosure**: Entirely optional at CV stage. If candidate requests accommodations, frame around strengths and small adjustments in the cover letter or designated portal fields.
- **AI Use Policy**: Use AI for structure, phrasing refinement, and keyword tailoring. Never generate fabricated facts, robotic cliches, or unverified claims.

## 6. Workflow: Adapting the LaTeX CV to a Job Description

When the user provides a target **Job Description (JD)** or role specification:

1. **Job Match & Gap Analysis (Tell the user if they match)**:
   - Calculate a **Match Score** (% compatibility based on hard skills, experience, and core qualifications).
   - Breakdown:
     * **Direct Strengths**: Qualifications, frameworks, and achievements that align 100% with requirements.
     * **Transferable Matches**: Areas where adjacent experience applies (e.g., using Linux administration & Docker for DevOps roles, or general networking for L2 support).
     * **Identified Gaps**: Requirements the candidate does not currently possess or needs to address.
     * **Verdict**: Clear verdict (*Strong Match*, *Good / Transferable Match*, or *Reach*).
2. **Title & Tagline Customization**:
   - Update the subtitle under the candidate's name to mirror the target role title and top 3–4 required competencies.
3. **Summary / Résumé Optimization**:
   - Tailor the 3–4 sentence summary paragraph to emphasize the exact background matching the job advert (e.g., highlighting hardware diagnostic and user support for Helpdesk roles, or Docker/Linux/Nginx for DevOps/Sysadmin roles).
4. **Experience Bullet Point Tailoring (Harvard Verbs + Metrics)**:
   - Reorder and refine bullet points using strong action verbs from [`action_verbs.md`](file://./references/action_verbs.md).
   - Ensure achievements quantify impact (e.g., reduction in processing time, ticket resolution, uptime).
5. **Technical Skills Re-prioritization**:
   - Group and prioritize the skills matching the job description first in the `Compétences Techniques` section.
6. **Output Full LaTeX Code**:
   - Deliver the complete, error-free, ready-to-compile `.tex` file so the user can immediately paste it into Overleaf or run `pdflatex`.

## 7. Pre-Submission Quality & ATS Audit Checklist

Before finalizing any CV or Resume, run through this 10-point audit:

- [ ] **Document Title Check**: Candidate's name is the header title; words "Curriculum Vitae" / "CV" / "Resume" are NOT present as title.
- [ ] **Zero First-Person Pronouns**: Thoroughly verify absence of `I`, `me`, `my`, `myself`, `we`, `our`.
- [ ] **Verb Lead-In**: Every bullet starts with a past-tense action verb (or present tense for active roles).
- [ ] **Quantification Check**: At least 50% of experience bullet points contain measurable metrics (%, £/$, numbers).
- [ ] **Contact Cleanliness**: Email is professional, phone has country code if needed, no DOB/photo/marital status.
- [ ] **Reverse Chronology**: Most recent roles and qualifications appear first in their respective sections.
- [ ] **Spacing & Margin Balance**: Margins are between 0.5 and 1 inch (or 2.0 to 2.5 cm); consistent spacing throughout.
- [ ] **Font Uniformity**: Max 2 font families; font sizes consistent (Header 18–22, Headings 13–15 bold, Body 10–11.5).
- [ ] **ATS Parse Readiness**: No floating text frames, icons, images, complex multi-column grids, or tables.
- [ ] **File Naming Convention**: Saved as `FirstName-LastName-CV.pdf` or `FirstName-LastName-Resume.pdf`.
